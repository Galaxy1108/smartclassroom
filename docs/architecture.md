## 总体结构

```
┌────────────┐   OneBot HTTP/WS   ┌──────────────────────────────┐
│  SnowLuma  │◄──────────────────►│        智慧课堂 App           │
│ （QQ 接入） │                    │  ┌────────────────────────┐  │
└────────────┘                    │  │ 消息管线 Pipeline       │  │
                                  │  │  分类 → 解析 → 执行     │  │
┌────────────┐   桥接 HTTP 5199   │  └────────────────────────┘  │
│ ClassIsland│◄──────────────────►│  AI 客户端 / 归档 / 调度门    │
│  + 插件    │   （通知、课表、换课）│  作业墙 / 事件页 / 课件索引   │
└────────────┘                    └──────────────────────────────┘
```

四个协作方：

| 组件 | 职责 |
|---|---|
| **SnowLuma** | 登录 QQ、注入 QQ 进程、把会话转成 OneBot v11（HTTP 动作 + WS 事件） |
| **智慧课堂 App** | 理解消息、执行动作、管理设置与界面 |
| **ClassIsland** | 教室里的课表与提醒宿主 |
| **插件** | App 与 ClassIsland 之间的桥：通知渠道、课表查询、换课写入 |

## 一条消息的旅程

```
QQ 消息
 │
 ├─ ① SnowLuma 推送 WS 事件
 │      → 解析（消息 / 文件 / 图片）；自发消息（message_sent）直接丢弃
 │
 ├─ ② 过滤：群是否监听？发送者是否在老师名单？功能是否开启？
 │      → 不通过就写一条"已忽略（原因）"并结束
 │
 ├─ ③ 建一条"进行中"的事件记录（界面开始转圈 + 计时）
 │
 ├─ ④ 分类：AI 判定 homework / exchange / summon / notice / none
 │      → 失败重试 3 次；仍失败则回退本地关键词并注明
 │
 ├─ ⑤ 按类别解析（各自的提示词契约）
 │      ├─ summon   → 目标、是否紧急、通知标题与正文
 │      ├─ homework → 科目、条目、日期、截止
 │      ├─ exchange → 涉及日期 → 取课表 → 换课类型与节次
 │      └─ notice   → 标题与正文
 │
 ├─ ⑥ 执行
 │      ├─ summon   → 调度门：紧急立即发，否则上课排队、下课时发
 │      ├─ homework → 作业墙（合并同科目同日期）
 │      ├─ exchange → 插件校验 → 写入临时层
 │      ├─ notice   → 调度门 → ClassIsland 提醒
 │      └─ 文件/图片 → 按科目归档 + 复制到系统下载目录
 │
 └─ ⑦ 收尾：把那条"进行中"记录就地变成结果行（已忽略 / 已执行 / 出现错误）
```

解析失败、类型未知、缺节次等情况会进入**待处理**，并在下课时提醒人工处理。

## 核心模块

| 模块 | 位置 | 职责 |
|---|---|---|
| 消息管线 | `src/Core/Pipeline.cs` | 过滤、分类、分发、记录事件行 |
| 规则与提示词 | `src/Core/RuleEngine.cs` | 本地关键词兜底 + 各角色提示词与 JSON 契约 |
| AI 客户端 | `src/Core/AI/` | `IAiClient` 双实现：pi-ai 边车 / OpenAI 兼容；统一重试与进度回调 |
| QQ 接入 | `src/Core/QQ/` | OneBot 客户端、事件解析、SnowLuma 管理（启动/注入/端口/凭据） |
| 归档 | `src/Core/FileArchive.cs` | 下载、去重、按科目落盘、元数据、系统下载目录镜像 |
| 调度门 | `src/Core/ScheduleGate.cs` | 上课排队、下课逐条发送、紧急立即发 |
| 课件索引 | `src/Core/CoursewareService.cs` | 按科目/日期检索，供课件页与上课弹窗使用 |
| 存储 | `src/Core/Stores.cs` | 作业、待处理、事件时间线（内存 + 原子落盘） |
| 界面 | `src/App/` | 作业墙、事件页、课件页、设置页（Avalonia + FluentAvalonia） |
| 插件 | `src/ClassIslandPlugin/` | 通知渠道、桥接 HTTP、课表接口、换课写入 |
| 边车 | `tools/ai-sidecar/` | 用 pi-ai 调各家模型，stdio JSONL 协议 |

## 数据与持久化

| 平台 | 位置 |
|---|---|
| Linux | `~/.local/share/SmartClassroom/` |
| Windows | `%LOCALAPPDATA%\SmartClassroom\` |

| 文件 | 内容 |
|---|---|
| `settings.json` | 全部设置（含 API Key、管理员密码哈希） |
| `state.json` | 作业、待处理、事件时间线（最近 200 条） |
| `ai-sidecar.log` | 每次 AI 请求一行 |
| `.instance.lock` | 单实例锁 |

**归档数据**（在用户指定的归档根下）：

```
<归档根>/
├── <科目>/
│   └── 课件.pptx                  ← 只放真正的文件
└── .smartclassroom-meta/
    └── <科目>/课件.pptx.json       ← 元数据（发送者、时间、来源）
```

写盘采用"先写临时文件再原子替换"，避免写一半断电留下坏文件。

## 关键设计取舍

| 取舍 | 原因 |
|---|---|
| 分类一律先问 AI，本地关键词只兜底 | 关键词会把"你上来把作业发一下"错判成作业 |
| 通知上课排队、下课时发 | 上课中弹提醒会打断课堂；紧急召唤例外 |
| 排队通知逐条等待显示完成 | 一次性全发会糊成一团 |
| 换课一律写临时层 | 不动周循环课表，出问题只影响那一天 |
| 插件不用 ASP.NET | ClassIsland 不带 ASP.NET Core 运行时，加载会直接失败 |
| 元数据放隐藏目录 | 科目文件夹里只有文件，便于直接翻看 |
| 单条消息异常不影响连接 | 一次解析异常曾把 WS 事件循环掀翻 |
| 设置与程序分开存放 | 覆盖安装不会丢配置 |
