## 功能开关

**默认全部关闭**，需要时逐个打开：

| 开关 | 打开后的行为 |
|---|---|
| 召唤通知 | 老师叫某人过去 → ClassIsland 通知 |
| 作业自动录入 | 作业消息 → 作业墙卡片 |
| 换课自动处理 | 换课消息 → 校验 → 写进临时层 |
| 群文件自动归档 | 老师发的文件/图片 → 按科目归档 |
| 上课课件弹窗 | 上课时弹出当天该科的课件 |
| 老师通知转发 | 活动/集合/催交等 → ClassIsland 提醒 |

## 前置门槛

集成没配好时，相关开关**不允许打开**（开关变灰并在下方写明缺什么）。
这样避免"打开了却什么都不发生"。

| 开关 | 需要 |
|---|---|
| 召唤通知 | QQ 就绪 + AI 就绪 |
| 作业自动录入 | QQ + AI |
| 换课自动处理 | QQ + AI + ClassIsland |
| 群文件自动归档 | QQ |
| 上课课件弹窗 | ClassIsland |
| 老师通知转发 | QQ + AI |

"QQ 就绪"指 OneBot 地址与令牌齐全（只监听私聊也算就绪）；"AI 就绪"指引擎、模型、
Key 齐全（pi-ai 引擎不需要服务地址）。

## AI

| 项 | 说明 |
|---|---|
| 引擎 | `pi-ai`（内置 Node 边车）或 OpenAI 兼容端点 |
| 服务商 / 模型 | pi-ai 引擎下从边车拉取 |
| 服务地址 | 仅 OpenAI 兼容端点需要 |
| API Key | 必填 |
| 推理强度 | 默认 `minimal`；调高更慢，详见 [ai.md](ai.md) |

## QQ 连接

| 项 | 说明 |
|---|---|
| SnowLuma 安装目录 | 应用据此启动/注入 |
| 班级 QQ 账号 | 多账号时选择注入哪个号 |
| OneBot HTTP / WS | 地址，由「自动分配端口」写入 |
| HTTP / WS 令牌 | **两个是分开的**，都要填 |
| 监听群号 / 选择群… | 只处理勾选的群 |
| 监听全部群 | 处理所有群（慎用） |
| 监听老师私聊 | 处理老师的私聊 |
| 只处理老师名单里的消息 | 默认开 |
| 由 AI 判定老师消息 | 默认开；关掉则只用本地关键词 |

详见 [qq-snowluma.md](qq-snowluma.md)。

## 老师映射

每一行是一位老师：**QQ 号、姓名/名片、科目**。

- 应用据此判断"谁有权触发"（默认只认名单里的人），以及文件的归档科目；
- 每行都有「编辑」：点它把该行填进下面的表单，按钮变成「保存修改」，可「取消」；
- 改完**立刻生效**：老师名单会热重载，不必重启。

## 外观

| 项 | 说明 |
|---|---|
| 主题 | 跟随系统 / 浅色 / 深色；也可点右上角按钮循环切换 |

## 科目颜色

设置页「科目颜色」列出**当前作业里出现过的科目** + 已配过色的科目，
每个科目一个颜色下拉（13 个预设色 + `默认`）。
`默认` 表示按科目名稳定取色板颜色（同一科目每次颜色一致）。
改完立刻生效 —— 配色也算进卡片指纹，下一轮刷新就换色。

## 安全与关闭行为

| 项 | 说明 |
|---|---|
| 管理员密码 | 设了之后，受保护操作需要验证 |
| 解锁后 10 分钟内免重复输入 | 默认关 |
| 关闭行为 | 关闭窗口 = 最小化到托盘，还是退出 |

### 管理员密码

设了密码后，**默认每一次修改操作都要重新输密码**：

- 设置页的任何改动（含启动/停止 SnowLuma、安装插件、清空日志、清空所有设置）；
- 作业页的手动添加/编辑/删除/拖拽排序；
- 事件页的重新解析、人工补录、忽略、清空时间线。

**解锁窗口默认 2 分钟**：每次要做需要密码的操作都会先验证，刚验证过的一小段时间不重复问。
想更严格就把窗口调小；想省事可以打开「解锁后 10 分钟内免重复输入」。
输错密码会提示"密码不正确"（连错 3 次提示稍后再试）。

> 没设密码时一切都不拦 —— 所以"密码没管住任何东西"通常是**还没设置密码**。

### 单实例

同一时间只允许运行一个应用实例：启动时先抢**互斥体**，再抢**锁文件**，
两个都被占用就提示"已在运行"并退出。这样不会出现两个实例抢同一个 OneBot 连接。

## 软件更新与调试

| 项 | 说明 |
|---|---|
| 检查更新 | 从 GitHub Releases 读取最新版本 |
| 立即更新（Windows） | 下载 zip → 解压到暂存目录 → 生成 `apply-update.cmd` → 退出后替换文件 |
| 调试：查看日志 | 设置页底部的操作日志 |
| 调试：清空所有设置 | 恢复默认（作业/事件等数据不动） |

Linux 上不提供自更新（用发行版包管理器）；Windows 走上面这套脚本替换。

## 生效方式

| 改动 | 生效时机 |
|---|---|
| 老师映射、功能开关 | **立即**（保存时热应用） |
| 群列表、监听开关 | 每条消息都读当前设置 |
| 归档根、下载目录复制 | 立即（归档配置就地更新） |
| 引擎、模型、Key | 下一次 AI 调用 |
| 主题、界面缩放 | 立即（并且**启动时会重新应用**，不会重置回默认） |

## 数据存放

| 平台 | 位置 |
|---|---|
| Linux | `~/.local/share/SmartClassroom/` |
| Windows | `%LOCALAPPDATA%\SmartClassroom\` |

| 文件 | 内容 |
|---|---|
| `settings.json` | 全部设置（含 API Key、管理员密码哈希） |
| `state.json` | 作业、待处理、事件时间线（保留最近 200 条） |
| `ai-sidecar.log` | 每次 AI 请求一行 |

写入采用"先写临时文件再原子替换"，避免写一半断电留下坏文件。
设置与程序分开存放，覆盖安装不会丢配置。
