# 快速开始

从零到"老师在 QQ 里说一句话，教室里就有反应"，大约十分钟。
本文按顺序给出安装、配置与验证步骤，每一步都能单独验证成功与否。

## 准备

| 需要 | 说明 |
|---|---|
| ClassIsland | 教室里的课表/提醒软件（可选，但召唤通知与换课需要它） |
| SnowLuma | QQ 接入层；**不需要**另外开一个 QQ 客户端 |
| 一个 AI 服务 | pi-ai 内置服务商（如 opencode）或任意 OpenAI 兼容端点 |
| 一台常开的电脑 | Linux 或 Windows 都可以；它同时跑 QQ 接入与应用 |

## 安装

**Linux（Arch 系）**

```bash
sudo pacman -U smartclassroom-<版本>-1-x86_64.pkg.tar.zst
```

**Windows**：解压 `smartclassroom-<版本>-win-x64.zip`，运行 `SmartClassroom.App.exe`。

**ClassIsland 插件**：启动应用 → 设置 → ClassIsland 集成 → 「安装插件」，
然后重启 ClassIsland。（也可以手动安装随包附带的 `smartclassroom-classisland-plugin.cipx`。）

## 配置

按设置页从上到下走一遍：

1. **AI**：选引擎（`pi-ai` 或 OpenAI 兼容端点）→ 服务商 → 模型 → 填 API Key。
   推理强度保持默认 `minimal` 即可。
2. **QQ 连接**：填 SnowLuma 安装目录 → 点「**启动注入**」
   （首次会让你确认 SnowLuma 的协议；Linux 还需要 `kernel.yama.ptrace_scope=0`，
   见 [QQ 集成](qq-snowluma.md)）→ 点「**自动分配端口**」把地址与两个令牌填好。
3. **老师映射**：加上老师的 QQ、姓名、科目。应用默认只处理名单里的人。
4. **监听范围**：用「选择群…」勾选要处理的群；需要私聊就打开「监听老师私聊」。
5. **功能开关**：按需打开。开关有前置门槛 —— 集成没配好时不允许打开，
   开关下方会写明缺什么。

## 验证

| 步骤 | 期望结果 |
|---|---|
| 看状态栏 | 显示「QQ 已连接」 |
| 让老师发一条消息 | 「事件」页出现一条记录，结尾写着判定来源与耗时 |
| 让老师发一个文件 | 事件页出现 `已执行：已归档`，文件落到 `<归档根>/<科目>/` |
| 打开一次「事件」页 | 能看到每条消息"为什么这么做" |

事件页是排查的第一入口：每条记录都写明了**判定来源**（AI / 本地）、
**耗时**与**三种结果**（已忽略 / 已执行 / 出现错误）。
