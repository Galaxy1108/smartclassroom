# 术语表

文档与界面里出现的名词，一页对齐。

## 角色与组件

| 名词 | 含义 |
|---|---|
| **智慧课堂 / SmartClassroom** | 本项目：把 QQ 消息变成教室里的动作 |
| **SnowLuma** | QQ 接入层：登录 QQ、注入 QQ 进程，对外提供 OneBot v11 接口 |
| **ClassIsland** | 教室里的课表与提醒软件，本项目的提醒都经它显示 |
| **插件（bridge）** | 装进 ClassIsland 的配套插件：通知渠道、课表接口、换课写入 |
| **边车（sidecar）** | `tools/ai-sidecar/sidecar.mjs`，用 pi-ai 调模型的 Node 子进程 |
| **桥接（bridge HTTP）** | 插件在 `127.0.0.1:5199` 起的极简 HTTP 服务，应用通过它调 ClassIsland |

## QQ 侧

| 名词 | 含义 |
|---|---|
| **OneBot v11** | QQ 机器人接口事实标准：HTTP 调动作、WebSocket 收事件 |
| **HTTP 服务 / WS 服务** | SnowLuma 为每个 QQ 号起的一对接口，**令牌是分开的** |
| **UIN** | QQ 号 |
| **正向 WS** | 由客户端（应用）连到 SnowLuma 的 WebSocket，用于收事件 |
| **message_sent** | OneBot 对"自己发出的消息"的标记，本项目一律忽略 |
| **注入** | 把 hook 打进正在运行的 QQ 进程（Linux 需要 `ptrace_scope=0`） |
| **老师映射** | 应用里的名单：QQ 号 ↔ 姓名 ↔ 科目；决定谁有权触发、文件归到哪个科目 |

## 消息处理

| 名词 | 含义 |
|---|---|
| **分类** | 判断消息属于 summon / homework / exchange / notice / none |
| **召唤（summon）** | 要求某人过去、上来或去某处；没点名也算 |
| **换课（exchange）** | 对调（Swap）、替换（Replace）或跨天（CrossDay） |
| **通知（notice）** | 老师向全班说一件事：活动、集合、催交、表扬等 |
| **待处理** | AI 没能自动处理、需要人工确认的事项 |
| **判定来源** | 该条结果是"AI 判定"还是"本地判定（原因）" |
| **降级** | AI 失败时回退到本地关键词或转人工 |
| **调度门（ScheduleGate）** | 决定通知"立即发"还是"上课排队、下课时发" |

## 数据与文件

| 名词 | 含义 |
|---|---|
| **归档根** | 存放老师文件的目录，结构为 `<归档根>/<科目>/<文件名>` |
| **元数据** | 文件来源信息，写在 `<归档根>/.smartclassroom-meta/` 下 |
| **课件索引** | 内存中的归档文件索引，供课件页与上课弹窗检索 |
| **系统下载目录** | 归档后额外复制一份的位置（QQ 靠它判断"已下载"） |
| **临时层** | ClassIsland 的按日期覆盖课表；换课只改它，不动周循环课表 |
| **课表接口** | 插件提供的 `GET /classplan?date=`，返回当天节次（临时层优先） |

## 状态与权限

| 名词 | 含义 |
|---|---|
| **功能开关** | 六个功能的总开关，默认全关 |
| **前置门槛** | 打开开关所需的集成条件（如"QQ + AI 就绪"） |
| **热应用** | 改设置后立即生效，不必重启 |
| **管理员密码** | 设了之后，修改类操作需要验证；默认每次操作都要 |
| **解锁窗口** | 验证通过后的免重复输入时间（默认 2 分钟） |
| **单实例** | 同一时间只允许一个应用实例运行 |
| **就绪（readiness）** | 设置页与状态栏对"QQ/AI 是否配好"的统一判定 |
