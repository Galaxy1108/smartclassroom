# ClassIsland 集成

[ClassIsland](https://github.com/ClassIsland/ClassIsland) 是教室里的课表与提醒软件。
智慧课堂通过一个**自带一键安装**的插件与它对接：把召唤、通知、换课结果变成课堂提醒，
并读取课表用于换课与课件弹窗。

## 插件安装

1. 应用 → 设置 → **ClassIsland 集成**；
2. 确认应用已找到 ClassIsland 数据目录（自动探测，也可手动指定）；
3. 点「**安装插件**」：应用把插件复制到 `<ClassIsland>/Plugins/smartclassroom.bridge/`
   并写好桥接令牌；
4. 重启 ClassIsland。

插件与应用的版本号一致（同一仓库、同一发版流程）。随包也提供
`smartclassroom-classisland-plugin.cipx`，可以在 ClassIsland 里手动安装。

**插件做了什么**

| 能力 | 说明 |
|---|---|
| 通知渠道 | 注册三个渠道：召唤通知 / 换课结果 / 手动请求 |
| 桥接 HTTP | 在本机 `127.0.0.1:5199` 起一个极简 HTTP 服务（不依赖 ASP.NET） |
| 课表接口 | `GET /classplan?date=yyyy-MM-dd` 返回当天节次（临时层优先） |
| 换课执行 | 直接读写 ClassIsland 档案，把换课写进临时层 |

> 桥接不用 Kestrel/ASP.NET：ClassIsland 是普通 .NET 应用，不带 ASP.NET Core 运行时，
> 插件里加载 `Microsoft.AspNetCore` 会直接 `FileNotFoundException`。这里用 BCL 的
> `TcpListener` 自己处理这几个请求，零框架依赖。

## 通知渠道

| 渠道 | 用途 | 图标 |
|---|---|---|
| 召唤通知 | 老师叫某人过去 | 喇叭 |
| 换课结果 | 换课自动处理的回执 | 双向箭头 |
| 手动请求 | 需要人工介入的事项 | 信息 |

通知内容使用 ClassIsland 的**模板数据类**并显式指定模板资源键
（`NotificationTwoIconsMaskTemplate` / `NotificationSimpleTextOverlayTemplate`）：
只塞字符串会渲染成类型名，不指定模板键会没图标、文字错位。
图标用 ClassIsland 自带 Fluent 字体的字形（按字形名取码位）。

## 通知什么时候发出去

| 消息 | 上课中 | 不在上课 |
|---|---|---|
| 召唤（`urgent: true`） | **立即发** | 立即发 |
| 召唤（普通） | 排队，下课时发 | 立即发 |
| 老师通知转发 | 排队，下课时发 | 立即发 |
| 需要人工介入 | 排队，下课时发 | 立即发 |

"下课时"有两个触发源：ClassIsland 的**下课/放学通知**（IPC），以及应用自己的
**状态轮询兜底**（每 15 秒检查一次"上课 → 不在上课"）。
后者是为了不依赖 ClassIsland 的通知设置 —— 万一那些通知被关掉，队列也不会永远卡住。

## 排队通知逐条发送

队列在下课时**一条一条**发：每条都等上一条**显示完成**再发下一条
（ClassIsland 的 `ShowNotificationAsync` 就是这个语义），另外还有 2 秒兜底间隔，
避免插件版本较旧时一次性全弹出来。

> 实测：不带等待的调用 66ms 返回；带等待 16s 返回（遮罩 8s + 正文 8s），
> 即确实在等提醒显示完。

## 读取课表

插件提供：

```
GET /classplan?date=2026-09-28
```

```json
{
  "date": "2026-09-28",
  "hasPlan": true,
  "isOverlay": false,
  "periods": [
    { "index": 1, "subject": "语文早自习", "start": "07:27", "end": "08:00" }
  ]
}
```

- **临时层优先**：走 ClassIsland 的 `GetClassPlanByDate`，它会先查按日期覆盖的临时层，
  再回落到周循环课表；返回的 `isOverlay` 表明这份课表是不是临时层；
- 用途一：换课解析时把相关日期的课表一起喂给 AI，让它把"周测改成语文"落到节次；
- 用途二：上课课件弹窗按"当天 + 当科"筛选课件。

## 换课与临时层

换课（对调 / 替换 / 跨天）**必须**写进临时层：`CreateTempClassPlan` 会深拷贝源课表，
挂到 `OrderedSchedules[date]` 做按日期覆盖，原周循环课表不受影响。

规则：

- 写入前先看那天有没有临时层，**有就复用**，所以同一天多次换课只会留下**一个**临时层；
- 同日对调在同一临时层内交换科目；跨天则在各自日期的临时层内互换；
- 校验不通过（日期已过、节次不存在、科目不存在、临时层创建失败）→ 不写入，
  转入**待处理**，并在下课时提醒人工处理。

## 上课课件弹窗

上课时（ClassIsland 的"上课"通知）按 **当天日期 + 本节课科目** 从归档索引里找课件：

| 规则 | 说明 |
|---|---|
| 同一天 + 同科目 | 必须同时满足 |
| 科目未知的文件 | 只有确认是**这位老师**发的才放行（一位老师一般只教一门课） |
| 一节课一次 | 同一科目同一天只弹一次 |
| 没有就不弹 | 当天该科没有课件时不打扰 |
| 窗口 | 标题「您可能需要的课件」，置顶、居中、显示后主动激活 |

设置页有「**预览上课弹窗**」按钮，可以先看效果。

## 排查

| 现象 | 原因与处理 |
|---|---|
| 通知没收到 | 看事件行是否写了"已执行：通知已转发（已排队）"；排队要等下课或状态轮询 |
| 通知一次性全弹出来 | 旧版插件不认识"等待"参数；重装最新插件 |
| 换课写不进去 | 事件页会写原因（缺节次 / 科目不存在 / 临时层创建失败），可转人工补录 |
| 课件弹窗没出现 | 事件页搜"上课弹窗"：`本节课没有科目信息` / 没有当天该科课件时不弹 |
| 插件装不上 | 确认 ClassIsland 数据目录被正确识别；安装后需重启 ClassIsland |
| 课表接口返回 `hasPlan: false` | 那天确实没有课表，或 ClassIsland 未连接 |
